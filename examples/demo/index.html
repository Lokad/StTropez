Opening the editor…

Change a value → inspect its type → follow its definition → rename it → compare → undo → save locally. Hover inspects a symbol; F12 follows its definition and F2 renames it. Code lists the commands. Place the caret on a symbol to highlight its uses: reads are shaded; writes also have an outline. Use Problems to find type errors. Embed these features in your IDE.
